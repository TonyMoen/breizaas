## Context & Background

### Project Vision
Breizaas is a professional artist website for an AI-generated Norwegian bygdemusikk artist with **125,000 monthly Spotify listeners**. This is not an experimental project - it establishes a credible digital presence for a proven musical success story, serving:
- Existing fans seeking tour dates and merch
- Event organizers evaluating booking decisions
- New audiences discovering AI-generated bygdemusikk

### Design Direction: V11 Warm Brown + Clean Vintage
The chosen design direction combines playful vintage warmth with sophisticated brown depth:
- Warm brown tones (earth tones, not cool charcoal)
- Clean vintage cream/beige for elevated surfaces
- Champagne gold accents (vintage luxury)
- Playful purple accents (AI innovation signal)
- Amber/orange lighting effects (golden hour atmosphere)
- Norwegian cabin warmth meets sophisticated lounge

**Differentiation:** Moves away from typical cold dark nightclub aesthetics to create a warmer, more culturally Norwegian feel while maintaining premium party energy.

### Architectural Foundation
- **Framework:** Next.js 15 with App Router (required for SSG/ISR)
- **Language:** TypeScript 5+ (strict mode)
- **Styling:** Tailwind CSS v4 (new @theme directive configuration)
- **Components:** shadcn/ui (accessible components on Radix UI)
- **Build Tool:** Turbopack (dev), Webpack (production)

## Implementation Details

### Step 1: Create Next.js Project

```bash
npx create-next-app@latest breizaas-website --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"
```

**Flag Explanations:**
- `--typescript`: Enable TypeScript with tsconfig.json
- `--tailwind`: Install and configure Tailwind CSS v4
- `--eslint`: Set up ESLint with Next.js recommended rules
- `--app`: Use App Router (required for SSG/ISR)
- `--src-dir`: Organize code in `src/` directory
- `--import-alias "@/*"`: Enable absolute imports

**Note:** This automatically configures Tailwind v4 (different from v3 configuration).

### Step 2: Initialize shadcn/ui

```bash
cd breizaas-website
npx shadcn@latest init
```

The CLI will prompt:
- **Style:** Default
- **Base color:** Neutral (we'll override with V11 colors)
- **CSS variables:** Yes
- **TypeScript:** Yes (already configured)
- **Import alias:** @/components
- **React Server Components:** Yes

### Step 3: Add Initial shadcn/ui Components

```bash
npx shadcn@latest add button card form input label
```

These components establish the foundation for:
- **Button:** CTAs, navigation
- **Card:** Tour dates, merch products
- **Form/Input/Label:** Booking and contact forms

## Developer Guardrails

### CRITICAL Architectural Rules

1. **Norwegian URL Structure:** All future routes MUST use Norwegian folder names
   - ✅ `src/app/musikk/page.tsx`
   - ❌ `src/app/music/page.tsx`

2. **Server Components by Default:** Do NOT add "use client" unless necessary
   - Only use for: forms, localStorage, event handlers, browser APIs

3. **Naming Conventions:**
   - React Components: PascalCase (`SpotifyEmbed.tsx`)
   - Utility files: camelCase (`formatDate.ts`)
   - Route folders: kebab-case Norwegian (`om-oss/`)

4. **TypeScript Strict Mode:** All code must pass strict type checking
   - No `any` types without explicit justification
   - Proper type definitions for all props

5. **Environment Variables:**
   - Server-only: `BANDSINTOWN_APP_ID` (no NEXT_PUBLIC_ prefix)
   - Client-safe: `NEXT_PUBLIC_SANITY_PROJECT_ID`
   - NEVER commit API keys to git

### Tailwind v4 Important Changes

**DO NOT use tailwind.config.js** - Tailwind v4 uses CSS-based configuration:
- ✅ Define colors with @theme in globals.css
- ❌ Do NOT create tailwind.config.js or tailwind.config.ts
- ✅ Use `--color-*` namespace for custom colors
- ✅ Import tailwindcss with `@import "tailwindcss"`

### V11 Color Usage Guidelines

**Background Hierarchy:**
- Primary page background: `bg-brown-dark`
- Section containers: `bg-brown-base`
- Elevated cards: `bg-cream-base`
- Hover states: `bg-brown-light`

**Text Hierarchy:**
- Headlines/primary: `text-text-primary` (warm white)
- Body text: `text-text-secondary` (lighter cream)
- Muted/secondary: `text-text-muted` (muted beige)

**Accent Usage:**
- Premium CTAs: `text-gold-champagne` or `bg-gold-champagne`
- Interactive elements: `text-purple-vibrant`
- Stats/numbers: `text-amber-glow`

**DO NOT:**
- Use pure white `#ffffff` - breaks warm aesthetic
- Use pure black `#000000` - too harsh
- Mix cool grays with warm browns - clashes with V11 palette
