# Breizaas Project Context

This file contains critical rules and patterns that AI agents must follow when implementing code for this project.

## Development Preferences

- TypeScript compilation checks still required

## Project Information

- **Project Name**: Breizaas
- **Type**: Artist website (Norwegian AI-generated bygdemusikk)
- **Framework**: Next.js 16.1.1 with App Router
- **Styling**: Tailwind CSS v4 (CSS-based @theme config)
- **TypeScript**: Strict mode enabled
- **Primary Language**: Norwegian (nb-NO)

## Critical Architectural Rules

### 1. NO tailwind.config.js
- Tailwind v4 uses CSS @theme in `globals.css`
- ✅ Add styles/utilities to @theme block
- ❌ Do NOT create tailwind.config.ts or tailwind.config.js

### 2. Server Components by Default
- ✅ Components should NOT have "use client" directive by default
- ✅ Only add "use client" when using hooks, events, or browser APIs

### 3. TypeScript Strict Mode
- ✅ All code must pass TypeScript strict mode
- ❌ No `any` types
- ✅ All props must be properly typed with interfaces

### 4. V11 Color System
- ✅ Use semantic color names: `bg-brown-dark`, `text-gold-champagne`, etc.
- ❌ Do NOT use raw hex values in className
- ❌ Do NOT use pure white (#ffffff) or pure black (#000000)
- See `globals.css` @theme block for full color palette

## Component Patterns

### Naming Conventions
- ✅ Component file: PascalCase `hero.tsx`
- ✅ Component name: `export function Hero()`
- ✅ Props interface: `HeroProps`

### Import/Export Pattern
```typescript
// ✅ Correct
export function Hero({ brandName, headline, stat }: HeroProps) {}

// ❌ Wrong
export default function hero() {}
```

### Responsive Classes (Mobile-First)
```typescript
// ✅ Correct - mobile-first approach
className="text-4xl md:text-5xl lg:text-6xl"

// ❌ Wrong - desktop-first
className="text-6xl lg:text-5xl md:text-4xl"
```

## Font Configuration

### Fonts in Use
- **Inter**: Body text, fallback
- **Trade_Winds** (Tradewind): Brand signature "BREIZAAS"
- **Montserrat Bold**: Headlines

### Font Loading Pattern
```typescript
// All fonts configured with display: 'swap'
const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
})
```

## Performance Requirements

- Page load < 2 seconds on 3G
- LCP < 2.5 seconds
- CLS < 0.1
- Font optimization with `display: 'swap'`

## Accessibility Requirements

- WCAG 2.1 AA compliance mandatory
- Semantic HTML required
- Proper heading hierarchy
- ARIA labels where appropriate
- Minimum 4.5:1 contrast ratio for normal text

## Known Issues to Avoid

❌ **Don't create tailwind.config.js** - Tailwind v4 doesn't use it
❌ **Don't use "use client" unnecessarily** - Adds JavaScript overhead
❌ **Don't hardcode Norwegian text in components** - Pass as props
❌ **Don't use Geist fonts** - Replaced with Inter, Trade_Winds, Montserrat
